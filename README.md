# 生活计算器

一个纯前端、零依赖的生活常用计算工具集合。单个 HTML 文件即可运行，所有计算都在浏览器本地完成，输入会自动保存在本地，刷新页面后继续保留。

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。

- 电脑端：左侧按分类浏览工具，顶部有历史、打印、深色模式和重置按钮
- 手机端：顶部下拉框切换工具，备案信息自动换行居中
- 侧栏搜索框可快速定位工具，「最近使用」中的条目可单独删除

## 工具清单（24 个）

**日常工具**：年龄计算器、日期计算器、工作日计算器、倒计时、预产期计算器、BMI 计算器、折扣计算器、单位换算

**房产**：房贷计算器、公积金贷款计算器、组合贷款计算器、二手房贷款计算器、房贷提前还款计算器、二手房交易税费计算器、租房 vs 买房

**汽车**：全款买车计算器、车贷计算器

**理财**：复利计算器、投资收益计算器、子女教育基金计算器、退休金测算

**家庭**：家庭月度收支计算器、个税计算器、五险一金计算器

## 说明

- 房贷相关计算器共用同一套还款引擎，支持等额本息与等额本金
- 房贷可展开前 24 期还款明细；家庭收支可保存每月账目并载入回看
- 税费比例、公积金利率、社保基数、节假日等参数均可自行修改，页面内标注了估算口径
- 计算结果仅供规划参考，实际金额以当地政策和机构核算为准
- 提供结果一键复制、打印样式与深色模式；备案信息不参与打印
